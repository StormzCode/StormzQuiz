StormzQuiz ⚡

This is a simple quiz platform designed for students to practice through randomly selected multiple-choice questions.

The platform focuses on quick practice, clean design, and instant feedback.

## ✨ Features

* 🧮 **Math** practice
* 📖 **English** practice
* 🧪 **Chemistry** practice
* 🎲 100 questions available for each subject
* 📝 40 randomly selected questions per quiz
* ✅ Instant correct/incorrect feedback
* 📊 Score tracking out of 40
* 💡 Question explanations
* 📚 Official SAT practice resource links

## 🎯 How Quizzes Work

Each subject contains **100 questions**.

When a quiz starts, StormzQuiz randomly selects **40 questions**.

For every question:

1. Select an answer.
2. Click **Check**.
3. See whether the answer is correct.
4. Receive the score.
5. Continue to the next question.

The maximum score is:

**40 / 40**

The score shown by StormzQuiz is a practice quiz score and is **not an official SAT score**.
